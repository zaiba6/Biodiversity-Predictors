# Website Showcase

Standalone website folder for presenting project results without mixing with analysis notebooks.

## Files

- `index.html` - main website page
- `styles.css` - styling and color theme
- `script.js` - tiny footer-date script
- `assets/Biodiversity-Predictors.pdf` - embedded project deck

## Run locally

Open `index.html` directly in your browser, or run a local server from this folder:

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).
